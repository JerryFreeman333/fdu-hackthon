# Route 2 产品旅程 V1

## 核心原则

Route 2 不再以“选择四个功能”作为用户旅程。Home Twin 是底层共享能力，用户看到的是与身份和任务相关的连续流程。

## 老人 / 居住者

目标：减少日常找东西和理解家庭信息的负担，不要求老人理解 3D、风险模型或家庭行动。

`家庭已准备好 → 找东西/找药 → 获得简单结果 → 复杂问题交给家人 → 回到日常使用`

当前 Demo：家庭空间预加载，因此“建立家庭空间”不由老人执行。真实产品中由子女/照护者完成初次采集。

## 子女 / 照护者

目标：用最少操作完成家庭建立、风险复核和处理闭环。

`首次建立家庭空间 → 系统分析 → 查看风险证据/影响范围 → 采取行动 → 重新扫描 → 风险确认关闭 → 后续查看变化`

## 为什么不是四个并列功能

- 安全巡检：是风险发现能力。
- 动线分析：是解释风险影响范围的能力，不是“预测老人实际路线”的独立产品。
- 家庭行动：是风险发现后的处理闭环。
- 找东西：是老人高频日常任务。

因此这些能力必须由旅程编排，而不是全部暴露成一级入口。

## Demo 验收

1. 用户第一次进入页面，能够立刻知道自己处于“老人”还是“家属/照护者”视角。
2. 老人视角看到“我的家 → 找东西”等日常任务，不需要进入风险分析页面。
3. 家属视角看到“家庭状态 → 风险证据 → 影响路线 → 处理/复扫”。
4. Demo 明确标示“家庭空间已预载”，避免让用户误以为自己刚刚完成了真实 3D 建模。
5. 用户完成一个动作后能知道下一步是什么，而不是停在某个孤立功能页。
6. 复扫完成后仍可回到家庭状态继续使用，形成回访闭环。
