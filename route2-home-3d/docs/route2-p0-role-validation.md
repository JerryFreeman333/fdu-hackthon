# Route 2 P0：用户角色分离验收

## 目标

验证 Route 2 不再把老人和子女/照护者当成同一种用户。

## 黑盒验收

### 老人视角

1. 首屏能够明确选择“我是老人”。
2. 一级入口只有“我的家”和“找东西”。
3. “找东西”可直接进入，不要求先理解 3D、Home Twin、动线或家庭行动。
4. 不出现“风险证据”“影响路线”“家庭行动”等家属工作项。
5. 页面明确说明复杂环境问题会交给家人处理，而不是要求老人自行判断风险。

### 子女/照护者视角

1. 首屏能够明确选择“我是子女/照护者”。
2. 一级入口为“家庭状态”“风险证据”“影响路线”。
3. 可以查看行动计划与复扫入口。
4. 可以从风险进入对应的空间证据。
5. 影响路线被定义为风险解释，不宣称预测老人实际行为。

## 失败判定

出现下列任一情况，即认为 P0 未完成：

- 老人首页仍直接展示安全巡检、动线分析、家庭行动三个技术/照护入口。
- 找东西仍需要经过家庭安全流程。
- 家属无法看到风险与处理闭环。
- 角色切换后上一角色的一级入口仍可见。
- 文案暗示系统已经准确预测老人行走行为。
