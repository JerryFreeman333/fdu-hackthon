# 手机拍摄指南（居家 3D 高斯泼溅重建）

> 目标：拍出一段适合 COLMAP + Gaussian Splatting 重建的素材。
> 核心原则一句话：**像绕着房间中心缓慢走圈一样拍，让每张照片之间有约 70% 的画面重叠。**

## 一、拍什么场景

针对"居家安全分析"这条路线，建议按**动线**分段拍摄，每段一个独立场景：

| 场景 | 覆盖内容 | 为什么单独拍 |
|------|----------|--------------|
| `bedroom` | 床、床头柜、床到门口的通道 | 夜间起夜动线起点 |
| `corridor` | 卧室到厕所/厨房的走廊、地毯、门槛 | 摔倒高发段 |
| `livingroom` | 客厅全景、沙发、茶几、插线板 | 主要活动区 |
| `bathroom` | 浴室门口与内部（**仅门口**，注意隐私） | 打滑风险 |

> 演示时选 1~2 个最有"故事性"的场景即可（推荐：卧室→走廊，能讲"夜间起夜"的故事）。

## 二、拍摄方式（二选一）

### 方式 A：视频（推荐，更简单）

1. 手机横屏，**1080p 或 4K、30fps**，关闭自动 HDR/夜景模式（避免帧间曝光突变）；
2. 一段拍 60~120 秒；
3. 运镜口诀：
   - 先绕房间中心**缓慢走一整圈**（脚步慢、手稳）；
   - 再在房间**四角各拍 30 秒**，镜头左右摇视房间中心；
   - 对准关键危险物（地毯、电线、台阶）**靠近拍 10 秒**；
4. 避免快速甩镜头、避免对准纯白墙面太久（特征点不足会匹配失败）。

### 方式 B：照片

1. 绕圈走，每走一小步拍一张，**总共 80~150 张**；
2. 相邻两张画面重叠约 70%；
3. 同样要有"绕圈 + 靠近"两种视角。

## 三、光照与环境要求

- **白天拍**，拉开窗帘，光线均匀，避免逆光对窗；
- 开全屋灯，避免一半亮一半暗；
- **不要有人或宠物在画面里移动**（动态物体会产生鬼影）；
- 镜头擦干净；关掉广角/超广角畸变过大的模式（1x 主摄最佳）；
- 镜子/镜面柜门尽量避开（会产生虚假特征点），避不开也没关系，COLMAP 通常能容错。

## 四、拍完之后

1. 把视频或照片传到电脑（微信文件传输助手 / QQ / 数据线均可）；
2. 运行管线：

```powershell
cd route2-home-3d\pipeline\scripts
# 视频方式
powershell -ExecutionPolicy Bypass -File run_all.ps1 -Video "C:\path\home.mp4" -Scene home
# 或照片方式
powershell -ExecutionPolicy Bypass -File run_all.ps1 -Photos "C:\path\photos" -Scene home
```

3. 全流程自动完成：抽帧 → COLMAP 相机标定 → 高斯泼溅训练 → 导出到 Web 演示端。

## 五、常见失败与排查

| 现象 | 原因 | 解决 |
|------|------|------|
| COLMAP 重建结果为空 | 照片重叠不足 / 墙面太白无特征 | 补拍，多走圈、降低移动步长 |
| 重建出多个碎片模型 | 视角覆盖不足 | 增加绕圈层数（高/低各一圈） |
| 训练 OOM（8GB 显存） | 分辨率/高斯数过多 | `04_train_3dgs.ps1 -Downscale 4`，或先 `-Iterations 7000` 预览 |
| 模型有"漂浮噪点" | 弱纹理区域 | 属正常现象，演示视角避开即可；可延长训练到 35000 步 |
