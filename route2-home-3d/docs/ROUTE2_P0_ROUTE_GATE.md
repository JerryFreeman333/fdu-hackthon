# Route 2 P0：Route Eligibility Gate

## 目标

防止 Web 端把“几何上可计算的路径”误包装成“已经验证安全的路线”。

当前 Route 2 只能在 Home Twin 证据足够时生成**可解释路线**，不能宣称医学安全或物理绝对安全。

## 当前 Gate

路线规划必须同时满足：

1. 床对象恰好一个。
2. 卫生间对象恰好一个。
3. 床与卫生间识别置信度均不低于 `0.6`。
4. 至少存在一条置信度不低于 `0.6` 的显式 `connects` 空间关系。
5. 床和卫生间不能位于 `blocks` 阻断集合中。
6. Dijkstra 回溯必须实际形成床到卫生间的连通路径。
7. 路径上的显式连接关系整体置信度不低于 `0.6`。

任何 Gate 失败都返回 `route: null` 与可解释原因，而不是生成猜测路线。

## 不变式

- 不允许多个候选床/卫生间时静默选择第一个。
- 不允许使用低置信度空间关系支撑最终路线。
- 不允许把 `route` 对外描述为已经证明“安全”。
- 未标定尺度时仍不得把坐标差解释为米；尺度保护属于后续 P0。

## 后续

P0-02 将继续加入绝对距离/尺度保护；P0-03 将加入复扫结果的来源、版本与风险 lineage，确保环境变化后旧风险不会被错误保留或自动消失。
