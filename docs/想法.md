# 项目想法脑暴（三条路线）

> 整理自团队的《想法》文档，作为选题与讨论的原始依据。

## 路线一：老年健康 Agent

最开始的想法是做一个面向老年人的 Agent，它不是单纯聊天，而是能持续了解老人状态、整理健康信息、在需要时联系家属或社区。

功能设想包括：

- 老人可以直接和 Agent 对话，像平时聊天一样说自己的身体状态、生活情况，比如"今天很累""最近走路有点喘""这两天睡不好""药忘记吃了"。
- Agent 可以从这些聊天内容里识别潜在问题，不一定直接判断疾病，而是发现"和平时不一样"的变化。
- 可以接手机、手表、健康 App，把心率、步数、睡眠、活动量、血氧等数据一起分析。
- 老人自己测血压、血糖、体重以后，不需要手动录入，可以直接拍血压计、血糖仪、体重秤，Agent 自动识别数据。
- 可以拍照上传体检报告，Agent 自动提取里面的重要指标，做长期记录和趋势比较。
- Agent 能把这些散落的数据整合起来，形成一个老人自己的长期健康档案。
- 可以结合老人过去的状态做"个人基线"，不是只看统一阈值，而是看这个老人最近是不是和自己平时不一样。
- 可以做每周健康周报，把这一周的血压、活动、睡眠、主观感受、异常变化整理给老人或者子女。
- 普通情况不打扰家属，出现持续变化或者明显风险时再通知子女。
- Agent 可以直接给子女发消息，比如"最近三天活动量持续下降，建议今晚联系一下老人"。
- 如果情况严重，可以进一步联系社区、社区医生或者医院，至少给出明确的联系路径。
- 还可以做老年人社群，老人平时可以聊天，AI 可以在群聊里识别一些潜在健康问题，比如有人反复说"最近总头晕""走两步就喘""脚肿了"，然后给予提示。
- 这个 Agent 还可以做传统陪伴功能，比如聊天、提醒、解释健康数据、回答生活问题。

大家特别喜欢"心衰/活动耐量下降"这个例子：老人可能只是觉得"最近很累"，但系统能结合步数下降、步速变慢、活动后心率变化、体重变化、睡眠变化、主观疲劳，发现状态正在恶化。

这个思路的核心不是"AI 诊断"，而是把老人模糊的"我最近有点累"变成可被持续观察的数据变化。

很多老人可能同时有高血压、糖尿病、心衰等慢病，所以 Agent 的价值在于把多个设备、多类数据合在一起看，而不是每个病一个 App。

**一句话概括**：做一个真正"认识这个老人"的健康 Agent，把对话、手表、血压、体检报告、用药和日常状态都放在一起看。

## 路线二：居家安全 3D 建模

后来想到的另一条完全不同的路。核心是用手机拍摄家里，做 3D 重建（比如 Gaussian Splatting），然后让 AI 理解这个老人的真实居住环境。

功能设想包括：

- 用手机拍家里，建立一个三维家庭模型。
- AI 自动分析家里的危险点：地毯翘边、电线横在通道、家具尖角、通道太窄、台阶、浴室打滑、没有扶手、照明不足、杂物挡路等。
- 重点是做"危险分析"，这是这条路线最重要的功能。
- 可以分析老人平时的主要活动动线，比如床到厕所、卧室到厨房、客厅到门口。
- 可以为老人规划更安全的行走路线。
- 可以做夜间动线分析，比如老人晚上起夜去厕所时，哪里最容易摔。
- 可以做逃生路线，比如发生火灾等情况时，给老人规划更容易走的路径。
- 可以帮助老人找东西，比如"我的眼镜在哪""钥匙放哪了""药在哪"，系统在 3D 家庭模型里标出位置。
- 这个功能对老年痴呆、轻度认知障碍老人可能很有用：老人忘了药放在哪里，系统可以直接语音告诉他，并在模型里给出路线。
- 也可以帮助照护者管理老人家里的物品和环境。
- 3D 的意义不是"做得炫"，而是单张照片很难理解空间关系，三维模型可以知道距离、通道、转角、障碍物和实际动线。
- 这条路线可以更强调"居家安全与行动能力"。

**一句话概括**：把老人家里变成一个可以被 AI 理解的 3D 空间，帮他找危险、找路线、找东西。

## 路线三：Agent + 3D 建模结合

讨论出来的融合思路：不是简单把两个功能拼一起，而是让 Agent 了解"人"，3D 模型了解"家"，然后两边联合判断。

- Agent 了解老人本人的健康状态：接入手表、手机、体检报告、血压、用药、聊天内容。
- 3D 模型了解老人家的空间环境：分析通道、家具、照明、障碍物、药品位置、活动路线。
- 系统最终判断的不是"这个家安全吗"，也不是"这个老人健康吗"，而是：**这个家，对现在这个老人来说安全吗？**

例子：

- 老人最近步速下降、活动量变少、夜间起床次数增加、老人自己说"最近有点头晕"——Agent 发现这个人的行动能力正在变化。
- 同时 3D 模型发现床到厕所这条路有地毯、窄转角、灯光不足。
- 那么系统就不是单独说"地毯有危险"，而是说：**由于老人最近行动状态变差，这块地毯和这条夜间路线现在风险更高。**

对应的思考入口：

- A1 第 2 条：早期变化与风险发现
- A1 第 5 条：居家安全与行动能力
- A1 第 1 条"父母与子女协同"作为最后闭环：平时不打扰子女 → 轻微变化先提醒老人 → 持续异常再告诉子女 → 严重风险时给出明确处理建议

融合路线里还可以把老年痴呆/认知障碍场景放进去：

- 老人忘了药在哪里 → Agent 知道他需要哪种药，3D 家庭模型知道药的位置 → 系统直接告诉老人并给路线。
- 如果老人长期找不到东西、重复询问、生活规律出现异常，也可以作为状态变化记录。

这条路线可以理解成 **Person Twin + Home Twin**：一个"人的数字画像"，一个"家的数字画像"，中间由 Agent 串起来。

## 共同原则

- 不要做成"万能养老平台"。
- 不要一上来就说 AI 能诊断疾病。
- 重点应该是"发现变化"和"帮助行动"。
- 老人使用方式要简单，最好能拍照、说话、自动同步，不要让老人填复杂表格。
- 不要过度监控老人，要强调只有需要时才通知家属。
- 开发时间短，所以三条路线里最好最终选一条主做。

## 三条路线对比

- Agent 路线最稳。
- 3D 路线视觉冲击力最大。
- 融合路线想法最完整，但开发量也最大。
