# 阿安 · 老人家庭助手

当前是单浏览器产品原型：支持首次身份选择、可跳过的家庭绑定、基本档案引导，以及老人端和家属端的独立导航。已接入可配置的 DeepSeek 开发后端；家庭建模、真实设备/照片识别、跨设备同步尚未接入。

## 使用流程

- 老人首次使用：选择身份 → 邀请家属或跳过 → 通过对话提供/跳过基本信息 → 自动保存 → 助手。
- 老人日常页面：助手 / 报告 / 我的。档案可在“我的”修改；编辑时可直接查看修改摘要。
- 家属页面：概况 / 健康报告 / 家庭环境 / 我的。未绑定不能查看报告，绑定后仍需老人共享授权。
- 家庭环境显示准备中，不收集家庭影像；旧拍照演示收在“我的”，仅预览示例，不写入本人记录。

## 档案与数据边界

本人档案包含称呼、年龄、确诊疾病、跌倒/骨折和恢复、行动辅助、夜间视力、平时起夜及用药。可以跳过并稍后补充；未知值不会被替换成演示值。资料通过校验后自动保存时间和本人填写来源，并进入 Agent Context / Person Twin；历史病史不会当作当天症状。

个人记录使用独立的 `ankang-personal-*` localStorage 键。旧版演示记录保留在原来的键中，不会自动导入个人资料。老人报告中可以独立查看演示报告；样例不会产生个人任务或参与本人风险计算。

## 共享与报告

- 绑定与授权分离，默认 `ask`。开启后只允许后续可共享记录进入家属页面，历史私密记录不补发。
- 家属报告从已授权事件重新计算，避免私密指标参与公开趋势；家属任务统一按绑定、授权、可见性过滤。
- 可在报告中只共享一条主诉，不需要开启长期共享。暂停全部共享会撤销单条授权并隐藏家属内容；不能收回家属已看过的内容。
- 同一浏览器、同一网址的页面同步权限及记录；可查看不代表已通知或已读。
- `private` 保留在老人自己的记录；
  `no_record` 不持久保存该轮健康事件和聊天。
- 周报使用任务实际完成时间；未知完成时间的历史任务不冒充本周完成。没有足够基线时显示信息不足。
- 标记任务完成只是处理记录，不代表健康或环境风险改善已经验证。

## 语音与对话

连续中文识别、实时临时转写、暂停后续录，默认点“说完并发送”结束并发送，可选择先检查文字；停顿不会自动发送。取消或离开页面停止录音；权限/网络错误不自动重试。识别准确率仍由浏览器服务决定。浏览器可能在线处理音频，应用的“不记录”设置不能控制该服务。

发送后立即显示用户消息和等待状态；同一时间只处理一条消息，失败可重试。回复可朗读和停止。配置 DeepSeek 后，自由对话使用真实模型；保留本地安全规则和明确的连接失败提示。

本地开发后端位于 server/deepseek.ts，随 Vite 启动。复制 .env.example 为 .env.local，填写 DEEPSEEK*API_KEY，重启服务；密钥不能放在 VITE* 前缀变量里。默认模型 deepseek-v4-flash，可通过 DEEPSEEK_MODEL 调整。构建后的静态文件不含该后端，部署时需另行提供同源服务。

资料问答将当前基本档案和本次自由回答交给模型，支持一次多项、纠正、插话。模型返回资料更新，经过字段、范围和原话依据校验后自动保存，支持继续纠正；不强制答完八项。点选回答可本地处理。普通聊天携带最近的非私密对话和已确认基本档案；明确“不记录/不外传”的输入留在本地。安全分级仍由既有规则决定。

## 启动和检查

```powershell
cd route1-health-agent
npm.cmd ci
npm.cmd run start:local
npm.cmd run ci
```

`start:local` 在后台启动固定地址 `http://127.0.0.1:5173/`，并检查网页后端是否就绪；重复执行不会重复启动。日志保存在 `.local/`。关闭终端后服务可继续运行，重启电脑后需要再次执行。需要在终端观察开发输出时仍可使用 `npm.cmd run dev`。

Windows 下若默认 npm 缓存无写权限，可使用
`npm.cmd ci --cache "$env:TEMP\codex-a1-npm-cache"`。

测试包括原有检测/数值/隐私测试，语音会话生命周期，以及档案校验、画像输入、家属权限、撤回、周报完成时间和本地日期回归。
`npm.cmd test` 与安全扫描支持 Windows。
